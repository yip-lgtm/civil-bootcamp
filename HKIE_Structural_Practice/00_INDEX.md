## 答題紀律（Section 1 MCQ 共用）
1. 先鎖定：**結構系統、support、load、construction stage、誰有 authority**。
2. 一個被忽略的條件足以改答案；絕對句（always / must / never）多數是 trap。
3. 分清四層規範：**法例 statutory → Code/PNAP → contract → good practice**。
4. 分清四種證明：**inspection / testing / certification / acceptance**。
5. Temporary condition ≠ permanent condition；未完成結構的 load path 往往不同。
