# 自學教程 00｜課程說明與學習方法
**Course Guide — From knowing design to knowing how to practise**

**對象**：Civil / Structural，Bachelor → HKIE Section 1 / 駐場／提交／臨時工程判斷  
**語言**：中英對照  
**原則**：不背條款當答案；先鎖條件，再選「在這些條件下唯一站得住的判斷」

---

## 1. 這套教程解決什麼問題？
**What problem does this course solve?**

大學與 MIT 軌道教你分析一個**已經存在**的結構。  
HKIE Section 1 與現場教你判斷四件大學較少考的事：

| 現場／考試真正問的 | 死背者的反應 | 本教程訓練的反應 |
|---|---|---|
| 結構尚未完成，今日穩不穩？ | 套竣工模型 | 重畫當日 load path |
| 發現偏差，接受／修／拆／停？ | 找一條「慣例」 | 問：力流、耐久、法定、合約各被傷到哪 |
| 文件很多，哪一份才算證明？ | 看見印章就安心 | 分清 inspection / test / cert / acceptance |
| 題目資料不齊 | 猜最像教科書的選項 | 找出**控制答案的那一個條件** |

## 2. 課程地圖
**Course map**

```
MIT CEE Structural Design / SMD     ← 已有軌道（識得設計）
        ↓
Tutorial 01  12週計劃

        ↓
M1  平衡・荷載路徑・桿架・SFD/BMD
M2  變形・作用組合・混凝土・鋼與組合
```

## 3. 每一課的固定學法（45–75 分鐘）
**How to study one lesson**

1. **默寫 5 個心智模型**（不看書，10 分鐘）  
   If you cannot say them in one sentence each, you do not own them yet.
2. **讀本模組「概念講解」**（20 分鐘）  
   只標兩種句子：條件句、以及「何時這句會反轉」。
3. **閉卷做 10 道深度題中的 4 道**（20 分鐘）  
   Write the *controlling condition*, not the whole essay.
4. **對答案，改自己的條件句**（15 分鐘）  
   錯通常不是公式，是漏了 stage / support / authority。
5. **本週產出**（見各模組末）  
   一張圖或一頁決策樹，能給別人看。

---

## 4. 四層規範（整套教程共用）
**Four layers of rules — never mix them**

1. **Statutory 法例**：Buildings Ordinance、BA 命令、可檢控義務。不能用合約豁免。  
2. **Code / PNAP**：被凍結的專家共識與審查協議。有適用範圍。  
3. **Contract 合約**：誰設計、誰付款、誰承擔延誤。只約束簽約方。  
4. **Good practice 良好慣例**：聰明、常見、但不是「必須」。MCQ 把慣例寫成 must 就是 trap。

答題口訣：  
**這句話是法律、是規範、是合約，還是只是聰明？**

---

## 5. 四種證明（整套教程共用）
**Four kinds of proof**

| 行為 | 它實際證明什麼 | 它沒有證明什麼 |
|---|---|---|
| Inspection | 當日看見的幾何／工序 | 強度、內部缺陷、未來行為 |
| Testing | 該試驗被設計去量的那一個量 | 構件整體、取樣以外的位置 |
| Certification | 簽署人對已知證據的專業聲明 | 未見之事、未做之試驗 |
| Acceptance | 合約上開始接收後果（付款／缺陷鐘） | 法定安全已被永久保證 |

---

## 6. 完成標準（你怎麼知道自己不是在背）
**Completion test**

合上書，隨機抽一張施工圖或一道 MCQ，你能在 90 秒內寫出：

1. 今日的 load path（不是竣工的）  
2. 控制極限狀態（強度／穩定／使用／耐久／法定閘門）  
3. 誰有 authority 做下一個決定  
4. 哪一個條件一改，答案就翻  

四項都能寫，這課才算過。
