## 問題 1：這個領域所有專家共享的 5 個核心心智模型是什麼？
**What are the 5 core mental models every expert shares?**

1. **Algorithm = precise steps + finite termination**  
   Correctness + complexity — two lenses。
2. **Abstraction 係 productivity**  
   Functions, classes, modules, libraries。
3. **Decomposition drives complex problem solving**  
   Top-down + bottom-up。
4. **Testing 係 engineering rigor**  
   Edge cases, regression, continuous integration。
5. **Computational thinking 對 real problems**  
   Formulation → algorithm → implementation → analysis。

---

## 問題 2：這個領域的專家在哪 3 個地方存在根本分歧？各方最強的論點是什麼？

1. **Python 對 first language vs stricter (C, Java)**  
   - Python: Friendly, slow.  
   - Strict: Discipline, performance.

2. **Procedural vs OOP**  
   - Procedural: Linear, simpler.  
   - OOP: Modular, scalable.

3. **Library-heavy vs from-scratch**  
   - Library: Productive, opaque.  
   - Scratch: Educational, inefficient.
