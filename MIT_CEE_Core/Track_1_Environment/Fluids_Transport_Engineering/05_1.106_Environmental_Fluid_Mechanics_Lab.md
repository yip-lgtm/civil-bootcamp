## 問題 1：核心心智模型

1. **實驗設計是對自然系統的提問**
   Experiments test hypotheses about fluid processes. The quality of experimental design (replication, randomization, blinding) determines what conclusions can be drawn.

2. **不確定性傳播是量化測量的核心**
   Uncertainty in outputs = propagation of uncertainties in inputs. Error analysis is not optional — it is the quantitative measure of confidence.

3. **尺度分析和相似性理論連接了實驗室與現場**
   Dimensional analysis (Buckingham π theorem) and similarity criteria (Froude, Reynolds, Peclet similarity) allow laboratory experiments to represent field conditions.

4. ** Residence Time Distribution 揭示了系統的混合特性**
   RTD E(t) = M(t)/M_total characterizes how long fluid elements spend in a system. RTD directly determines reaction conversion.

5. **儀器誤差和統計誤差的區別是數據分析的起點**
   Random errors: reducible by replication. Systematic errors: identifiable and correctable. Blunders: preventable by careful procedure.

# 核心心智模型深化

## 1. 實驗設計與誤差分析

### 1.1 Bilingual 概念對照
| English | 中英對照 | 定義 | 工程應用 |
|---|---|---|---|
| Systematic error | 系統誤差 | Consistent bias, not reducible by averaging | Instrument calibration |
| Random error | 隨機誤差 | Statistical variability, reducible by N | Replication |
| Propagation | 傳播 | σ_y = √((∂f/∂x)²σ_x²) | Combined uncertainty |
| Significant figures | 有效數字 | Precision of measurement | Reporting |

### 1.2 Key Derivation — Error Propagation
For y = f(x₁, x₂, ..., x_n):
σ_y² = Σ (∂f/∂x_i)² σ_{x_i}² + 2Σ (∂f/∂x_i)(∂f/∂x_j)COV(x_i, x_j)

For independent measurements (COV = 0):
σ_y = √(Σ (∂f/∂x_i)² σ_{x_i}²)

**Example**: y = k·x, σ_y/y = σ_k/k ⊕ σ_x/x (fractional uncertainties add in quadrature)

### 1.3 Experimental Design
- **Replication**: n ≥ 3 for each treatment
- **Randomization**: Order of runs randomized
- **Blinding**: Where possible, measurement blind to treatment

## 2. 離散與分散

### 2.1 Fick's Laws
**First law**: J = −D ∂C/∂x (flux proportional to gradient)
**Second law**: ∂C/∂t = D ∂²C/∂x² (diffusion equation)

**Molecular diffusion coefficient** D:
- Air: D ≈ 2×10⁻⁵ m²/s
- Water: D ≈ 2×10⁻⁹ m²/s (10,000× smaller)

### 2.2 Taylor Dispersion
In laminar pipe flow, the effective dispersion coefficient:
D_eff = D + K·a²U²/D

Where:
- a = pipe radius
- U = mean velocity
- K = 1/48 for laminar flow (Taylor 1953)
- For turbulent flow: D_eff ≈ 10aU

**Example**: Water in 1 cm diameter pipe, U = 0.1 m/s, D = 2×10⁻⁹ m²/s
K·a²U²/D = (1/48)×(5×10⁻³)²×(0.1)²/(2×10⁻⁹) = 2.6×10⁻⁵/2×10⁻⁹ = **13,000** → D_eff ≈ 13,000 × D

**Dispersion dominates molecular diffusion by ~13,000×!**

## 3. Residence Time Distribution

### 3.1 Key Formulas
**RTD function** E(t) = C(t)/∫₀^∞ C(t)dt

**Mean residence time**: t_mean = ∫₀^∞ t·E(t)dt
**Variance**: σ² = ∫₀^∞ (t − t_mean)²·E(t)dt

**For ideal CSTR (continuous-flow stirred tank)**:
E(t) = (1/τ) e^{−t/τ}, t_mean = τ, σ² = τ²

**For ideal PFR (plug flow reactor)**:
E(t) = δ(t − τ), t_mean = τ, σ² = 0

**Dispersion model (Bodenstein number Bo = UL/D)**:
σ²/τ² = 2/Bo (for Bo > 100, Gaussian RTD)

### 3.2 Engineering Applications
- **Water treatment**: RTD determines disinfectant contact time (Ct values)
- **River mixing**: RTD determines pollutant dilution
- **Wetland design**: Long t_mean → more treatment, larger footprint

## 4. 表面波與尺度分析

### 4.1 Dimensionless Parameters
**Froude number**: Fr = V/√(gD) = inertial/gravitational
- Fr < 1: Subcritical (gravity-dominated)
- Fr > 1: Supercritical (inertia-dominated)
- Fr = 1: Critical flow

**Reynolds number**: Re = VL/ν = inertial/viscous

### 4.2 Wave Phase Speed
Deep water (h/λ > 0.5): c = √(gλ/2π) (dispersion)
Shallow water (h/λ < 0.05): c = √(gh) (non-dispersive)

**Wave breaking**: When wave slope H/λ > 1/7 (Stokes limit), breaking occurs.

## 總結

1. **實驗設計決定了結論的強度**：隨機化、重複、盲法——這些基本原則是不可妥協的
2. **誤差傳播是量化測量不確定性的數學框架**：σ_y = √(Σ(∂f/∂x)²σ_x² 是所有工程師都必須掌握的工具

4. **停留時間分佈揭示了混合過程**：E(t) 函數是診斷水處理和自然系統混合特性的診斷工具
5. **表面波實驗連接了流體力學與環境界面過程**：波浪破碎、沿岸漂移、濕地水動力——這些都是環境流體力學的核心應用
