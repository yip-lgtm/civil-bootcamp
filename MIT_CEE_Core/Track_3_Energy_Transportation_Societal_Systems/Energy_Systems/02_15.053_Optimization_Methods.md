## 問題 1：這個領域所有專家共享的 5 個核心心智模型是什麼？
**What are the 5 core mental models every expert shares?**

### Mental Model 1 — Every Real-World Decision Is an Optimization Problem
Every operational, financial, and strategic decision can be expressed as
$$\min_{x \in \mathbb{R}^n} f(x) \quad \text{subject to} \quad g_i(x) \leq 0, \; h_j(x) = 0.$$
Prof. Orlin (MIT 15.053 lecture notes, 2010s): *"The goal in 15.053 is to help you develop an 'optimization mindset' — to look at the world and see optimization problems everywhere, and to recognize when these problems can be modeled, analyzed, and solved."* This framing descends from Dantzig's (1963) *Linear Programming and Extensions*, where he formalized the dichotomy between *descriptive* models (which explain data) and *prescriptive* models (which recommend action). Optimization is the canonical prescriptive formalism.

**Industry evidence** (Orlin 2010; *Annals of Operations Research* 2014 surveys):
- United Airlines crew scheduling saves ≈ \$40M/year by formulating pairings as a **set partitioning IP** (Anbil et al. 1991, *Interfaces*).
- FedEx ORION routing saves ≈ \$100M/year on a vehicle routing problem with time windows (VRPTW) of ≈ 200,000 stops/day (Goodson 2015, *INFORMS Analytics*).
- Walmart's procurement optimization (Schrage 2005, *Optimization Stories*) cut inventory by 16% while raising in-stock rates.
- McKinsey (2018) estimates firms using prescriptive analytics are 2.2× more profitable than peers using only descriptive analytics.

**Constructive test**: If you cannot write the objective, the decision variables, and the constraints, you do not yet understand the decision.

---

### Mental Model 2 — Geometry Leads, Algebra Follows (LP Geometry & Duality)
The feasible region $\{x \in \mathbb{R}^n : Ax \leq b, x \geq 0\}$ is a **polyhedron**; the optimal solution of any LP lies at a vertex (basic feasible solution, BFS). This geometric fact is the foundation of:
- **Simplex method** (Dantzig 1947): walks along edges of the polyhedron, improving the objective at each pivot. Worst-case exponential (Klee & Minty 1972), but in practice $O(2m\text{–}3m)$ iterations (Dantzig & Thapa 1997, Ch. 2).
- **Interior point** (Karmarkar 1984): polynomial-time interior traversal, $O(n^{3.5}L)$ where $L$ = input bit-length (Nesterov & Nemirovskii 1994).
- **Strong duality**: $\min c^Tx \text{ s.t. } Ax = b, x \geq 0 = \max b^T\lambda \text{ s.t. } A^T\lambda \leq c$. The geometric content: the primal optimum equals the dual optimum because both represent the *same hyperplane* supporting the feasible region (Rockafellar 1970, *Convex Analysis*, §19).

**Markowitz (1952) portfolio frontier** as geometric example:
$$\min_{w \in \mathbb{R}^n} w^T\Sigma w \quad \text{s.t.} \quad \mathbf{1}^Tw = 1, \; \mu^Tw = r_p.$$
The feasible region is a 1-dimensional curve (the efficient frontier); the dual parameter $\lambda$ traces it out. Merton (1972, *Journal of Financial Economics*) extended this to dynamic multi-period optimization. The Capital Asset Pricing Model (Sharpe 1964; Lintner 1965; Mossin 1966) is recovered as the KKT condition of an equilibrium optimization.

**Saddle-point interpretation**: $c^Tx^* = \max_{\lambda} \min_x L(x, \lambda)$. This is the deepest geometric insight: duality is *game-theoretic* (von Neumann 1928; Gale, Kuhn & Tucker 1951).

---

### Mental Model 3 — Relaxation Is the Engine of Integer Programming
For $\max c^Tx$ s.t. $Ax \leq b, x \in \mathbb{Z}^n_+$:
- **LP relaxation** $P = \{x : Ax \leq b, x \geq 0\}$ contains all integer points but is "rounded".
- $z_{LP} \geq z_{IP}$ (max); the **integrality gap** is $(z_{LP} - z_{IP})/z_{IP}$.
- **Branch-and-bound** (Land & Doig 1960): recursively branch on fractional variables, fathoming with LP-relaxation bounds.
- **Cutting planes** (Gomory 1958; Balas 1965): valid inequalities $a^Tx \leq b$ cutting off fractional vertices without excluding integer points.
- **Lagrangian relaxation** (Held & Karp 1970, 1971): for TSP, the bound $\leq 0.5\%$ from optimal on 1,000-city instances; for uncapacitated facility location, within 0.5% on 1,000-node random instances.

**Why relaxation works**: The relaxed polytope's *integrality* is the gap. Closing the gap = making the polyhedron integral = the *holy grail* of IP theory (Chvátal 1973; Wolsey 1975; Carr & Lancia 2000 — all addressing facets of integer hulls).

**Numerical illustration** (Winston 2004, Example IP.1): $\max 3x_1 + 2x_2$ s.t. $2x_1 + x_2 \leq 6, x_1 + 2x_2 \leq 4, x_j \in \mathbb{Z}_+$. LP optimum $z_{LP} = 28/3 \approx 9.33$ at $(8/3, 2/3)$; IP optimum $z_{IP} = 9$ at $(3, 0)$. Gap = 3.7%. Branch-and-bound needs only 3 nodes.

### Mental Model 4 — Duality Bridges Theory and Computation
Duality is not merely a theorem — it is a *computational engine*. Specific uses (Bertsimas & Tsitsiklis 1997, §4; Nemhauser & Wolsey 1988, §II.2):

| Concept | Equation | Use |
|---|---|---|
| Primal-dual pair | $\min c^Tx, Ax = b, x \geq 0 \leftrightarrow \max b^T\lambda, A^T\lambda \leq c$ | Same optimum, two views |
| Complementary slackness | $x_j > 0 \Rightarrow (A^T\lambda^*)_j = c_j$ | Tight pricing = used resource |
| Shadow price | $\lambda_i^* = \partial z^*/\partial b_i$ | Marginal value of resource $i$ |
| Dual simplex | Solve by maintaining dual feasibility | Network flow, re-optimization |
| Column generation | Reduced cost $c_j - \lambda^T A_j < 0$ triggers column | Dantzig-Wolfe 1960 decomposition |
| Lagrangian bound | $\max_{\lambda \geq 0} \min_{x \in X} L(x, \lambda)$ | Lower bound on IP via relaxation |
| Perturbation analysis | $dz^*/db_i = \lambda_i^*$ | Sensitivity analysis, post-optimality |

**The economic content**: $\lambda_i^*$ is the *willingness to pay* for one unit of resource $i$. In production planning, this informs capital budgeting — buy another machine hour if its shadow price exceeds its marginal cost (Reiterman 1984, *Interfaces*).

**The computational content**: every modern LP solver (CPLEX, Gurobi, MOSEK, HiGHS) uses primal-dual interior-point methods (Mehrotra 1992) or dual simplex variants (Maros & Meszaros 1996). The dual is not optional.

### Mental Model 5 — Heuristics Provide Good Enough for What Is Impossible
For NP-hard problems — TSP (Karp 1972, *Complexity of Computer Computations*), VRP (Lenstra & Rinnooy Kan 1981), scheduling (Garey & Johnson 1979) — optimal algorithms are exponential in worst case. Yet real logistics, scheduling, and combinatorial problems must be solved daily. Resolution:

| Method | Guarantee | Reference |
|---|---|---|
| Greedy | $\log n$-approx for set cover | Johnson (1974); Chvátal (1979) |
| Local search | Local optimum; no guarantee | Papadimitriou & Steiglitz (1982) |
| Simulated annealing | Probabilistic global optimum | Kirkpatrick et al. (1983) |
| Genetic algorithms | No guarantee; empirical | Goldberg (1989) |
| Tabu search | Beats local optima; no guarantee | Glover (1986, 1989, 1990) |
| ALNS | Empirical 1–3% gaps at scale | Pisinger & Røpke (2007); Røpke & Pisinger (2006) |
| Approximation algorithms | Provable $\rho$-approximation | Hochbaum (1997); Vazirani (2001) |

**Industry reality** (Google OR-Tools documentation 2023; Pisinger & Røpke 2007): Adaptive Large Neighborhood Search (ALNS) solves 10,000-stop VRPTW in < 1 minute with ≈ 1.1% optimality gap, where exact MILP would require days. Christofides (1976) gave a 1.5-approximation for metric TSP, improved to 1.4-$\epsilon$ by Karlin, Klein & Oveis Gharan (2021, *Annals of Mathematics*).

**The pedagogical reality**: Prof. Orlin's 15.053 has always taught both — optimal algorithms for tractable cases, heuristics for intractable. The 21st-century insight is that the *boundary* between exact MILP and heuristics shifts with hardware and solver engineering; a problem solved exactly today was heuristic-only a decade ago (Bixby 2012, *Interfaces*; Koch et al. 2011).

## 問題 2：這個領域的專家在哪 3 個地方存在根本分歧？

### Disagreement 1 — Exact MILP vs. Heuristics

**Position A — Exact MILP is sufficient** (Bixby 2002, 2012; Achterberg & Wunderling 2013): Modern MILP solvers — branch-and-cut with cutting planes, conflict analysis, presolve, parallelism — solve problems with millions of variables optimally. Bixby (2012, *Interfaces*, *"A Brief History of Linear and Integer Programming"*): from 1991 to 2012, MILP solver speed improved by a factor of ≈ 500,000× — a combination of algorithm and hardware. Gurobi 10.0 (Gurobi Optimization 2023) routinely solves MILPs of 100K+ variables to 0.01% optimality in hours.

**Position B — Heuristics win at scale** (Glover 1986, 1989, 1990; Kochenberger & Glover 2003; Pisinger & Røpke 2007): For truly massive problems (1M+ variables), even the best MILP solvers fall back to heuristic mode. Metaheuristics — tabu search, scatter search, ALNS — are the de facto winners in:
- Real-time vehicle routing (UPS ORION, FedEx, DHL),
- Crew scheduling (Anbil et al. 1991, with post-hoc MILP polish),
- Production scheduling at scale,
- Hyperparameter optimization in machine learning (Bergstra & Bengio 2012).

**Core tension**: The line moves. A 1970 problem solved by heuristic is solved exactly by 2024. But the size of "interesting" real problems grows faster than solver speed (Bixby 2002 acknowledges this). Glover's (1990) **scatter search** and Pisinger & Røpke's (2007) **ALNS** outperform MILP for 10K-stop VRPTW in < 1 minute — a regime where exact MILP is hopeless. The truth is **bifurcated**: small/medium problems → exact; large/real-time → heuristic.

---

### Disagreement 2 — Modeling-First vs. Algorithm-First

**Position A — Modeling is the bottleneck** (Williams 2013, *Model Building in Mathematical Programming*, 5th ed.; Dantzig 1963): The key skill is formulating real problems correctly. *"A well-formulated problem is half solved."* Bad formulation → no solver can help. Williams documents dozens of cases where reformulation turned "unsolvable" into "trivial" — e.g., transportation as min-cost flow, assignment as bipartite matching, knapsack with cover inequalities.

**Position B — Algorithm structure dominates** (Bertsimas & Tsitsiklis 1997; Papadimitriou & Steiglitz 1982; Ahuja, Magnanti & Orlin 1993): Know your problem class. Shortest path = $O(m + n\log n)$ via Dijkstra + Fibonacci heap (Fredman & Tarjan 1987). Assignment = $O(n^3)$ via Hungarian (Kuhn 1955; Munkres 1957). Max-flow = $O(VE^2)$ Edmonds-Karp or $O(V^2\sqrt{E})$ Dinic. General MILP = exponential. The algorithm determines what *can* be solved; the formulation is downstream.

**Core tension**: This is a false dichotomy in practice. Both are required. The synthesis — **"modeling for algorithms"** — is the heart of the OR tradition. Example: assignment can be modeled as general MILP (works, slow) or as bipartite matching with Hungarian (fast). The same problem, two formulations, two orders-of-magnitude difference. This is why 15.053 spends half its time on formulation: it is the *enabling* condition for the right algorithm.

Ahuja, Magnanti & Orlin (1993, *Network Flows*) is the canonical statement: problem structure ⇒ polynomial algorithm ⇒ tractable.

---

### Disagreement 3 — Deterministic vs. Stochastic Optimization

**Position A — Deterministic optimization is the foundation** (Bradley, Hax & Magnanti 1977; Winston 2004; most of standard OR textbook practice): Sensitivity analysis (Lagrangian multipliers) reveals robustness; $\partial z^*/\partial b_i$ tells you how much each constraint is worth. Deterministic models are interpretable, verifiable, and fast. Real-world uncertainty is handled by *robust* perturbation (shadow price intervals) or *sensitivity reports* (e.g., CPLEX output).

**Position B — Uncertainty is the rule, not the exception** (Dantzig 1955; Beale 1955; Birge & Louveaux 2011; Shapiro, Dentcheva & Ruszczynski 2014): Real decisions have uncertain parameters. Two-stage stochastic programming:
$$\min_{x \in X} c^Tx + \mathbb{E}_\xi[Q(x, \xi)]$$
$$Q(x, \xi) = \min q(\xi)^Ty \quad \text{s.t.} \quad W(\xi)y = h(\xi) - T(\xi)x, y \geq 0.$$
Sample Average Approximation (SAA; Shapiro 2003; Kleywegt, Shapiro & Homem-de-Mello 2002):
$$\min \frac{1}{S}\sum_{s=1}^S c^Tx + q_s^Ty_s \quad \text{s.t.} \quad W_s y_s = h_s - T_s x, \forall s.$$
Distributionally Robust Optimization (DRO; Mohajerin Esfahani & Kuhn 2018; Delage & Ye 2010) interpolates: optimize against worst-case distribution within a Wasserstein ball.

**Core tension**: Stochastic models are computationally intractable for large networks (curse of dimensionality — $S$ scenarios, $n$ variables each, $Sn$ total). Practical compromises: Benders decomposition (Benders 1962; Geoffrion 1972), Progressive Hedging (Rockafellar & Wets 1991), or scenario reduction (Dupacová, Gröwe-Kuska & Römisch 2003). The synthesis: deterministic for planning, stochastic for capital decisions under deep uncertainty (Ben-Tal & Nemirovski 1998, 1999; Bertsimas & Sim 2004 for robust LP).

### Deep Dive 1 — Linear Programming: Simplex, Duality, and Sensitivity
**線性規劃：單純形法、對偶性、與敏感度分析**

#### Bilingual Concept Map

| English | 中英對照 | Definition | 物理意義 |
|---|---|---|---|
| Linear program (LP) | 線性規劃 | $\min c^Tx, Ax \leq b, x \geq 0$ | 目標與約束均為線性 |
| Basic feasible solution (BFS) | 基本可行解 | Vertex of a polyhedron | 約束邊界交集 |
| Reduced cost | 簡化成本 | $\bar{c}_j = c_j - c_B^T B^{-1}A_j$ | 進入變數潛在改善量 |
| Shadow price | 影子價格 | $\partial z^*/\partial b_i = \lambda_i^*$ | 資源邊際價值 |
| Dual LP | 對偶線性規劃 | $\max b^T\lambda, A^T\lambda \leq c$ | 原始問題之鏡像 |
| Sensitivity analysis | 敏感度分析 | Range of $b_i, c_j$ for which $x^*$ remains optimal | 解的穩健性區間 |

#### First-Principles Derivation of the Simplex Method (Dantzig 1947)

**Standard form LP**: $\min c^Tx$ subject to $Ax = b$, $x \geq 0$, $b \geq 0$.

**Decomposition**: Partition $x = [x_B, x_N]$ with basis $B$ (invertible $m \times m$) and non-basic $x_N = 0$. Then $x_B = B^{-1}b$ uniquely.

**Optimality test**: Reduced costs $\bar{c}_N^T = c_N^T - c_B^T B^{-1}N \geq 0$. If all $\bar{c}_j \geq 0$, current BFS is optimal.

**Entering variable**: $j^* = \arg\min_j \bar{c}_j$ (most negative reduced cost).

**Leaving variable** (minimum ratio test, to preserve feasibility): 
$$i^* = \arg\min_{i: \bar{a}_{ij^*} > 0} \frac{(B^{-1}b)_i}{\bar{a}_{ij^*}}$$

**Pivot operation**: Exchange column $i^*$ of $B$ for column $j^*$ of $N$. Update basis inverse via LU or product form.

**Tableau form**:
| Basic | RHS | $x_1$ | $x_2$ | $\cdots$ | $x_n$ |
|---|---|---|---|---|---|
| $z$ | $z_0 = c_B^T B^{-1}b$ | $\bar{c}_1$ | $\bar{c}_2$ | $\cdots$ | $\bar{c}_n$ |
| $x_{B_1}$ | $\bar{b}_1$ | $\bar{a}_{11}$ | $\bar{a}_{12}$ | $\cdots$ | $\bar{a}_{1n}$ |
| $\vdots$ | $\vdots$ | $\vdots$ | $\vdots$ | $\ddots$ | $\vdots$ |
| $x_{B_m}$ | $\bar{b}_m$ | $\bar{a}_{m1}$ | $\bar{a}_{m2}$ | $\cdots$ | $\bar{a}_{mn}$ |

**Convergence**: Simplex visits one BFS per iteration. Max iterations $\binom{n}{m}$; in practice $2m\text{–}3m$ (Dantzig & Thapa 1997, *Linear Programming* Vol. 1, §2.4). Worst case exponential: Klee-Minty hypercube (1972) requires $2^n - 1$ pivots. But smooth/perturbed analysis (Spielman & Teng 2004) gives polynomial expected time.

**Interior-point alternative** (Karmarkar 1984, *Combinatorica*): polynomial-time algorithm $O(n^{3.5}L)$; current implementations use primal-dual Mehrotra (1992) predictors. CPLEX, Gurobi, MOSEK all default to interior point for large LPs.

#### Strong Duality and Complementary Slackness

**Weak duality**: For feasible $x$ primal, $\lambda$ dual, $c^Tx \geq b^T\lambda$.

**Strong duality**: If both feasible and one has bounded optimum, $\min c^Tx = \max b^T\lambda$.

**Proof via Farkas' Lemma** (Schrijver 1986, *Theory of Linear and Integer Programming*, §2.2): For any feasible $x$, $c^Tx = (c - A^T\lambda)^Tx + \lambda^T b$. Since $c - A^T\lambda \geq 0$ and $x \geq 0$, $(c - A^T\lambda)^Tx \geq 0$. Hence $c^Tx \geq \lambda^T b$. Equality follows from complementary slackness at optimal basis.

**Complementary slackness** (Gale, Kuhn & Tucker 1951):
$$x_j^* > 0 \Rightarrow (A^T\lambda^*)_j = c_j, \quad \lambda_i^* > 0 \Rightarrow (Ax^*)_i = b_i.$$

#### Engineering Applications

- **Refinery blending** (Magou & Tzieropoulos 2013, *Interfaces*): mix crude oils to meet octane/sulfur specs at minimum cost.
- **Portfolio optimization** (Markowitz 1952): $\min w^T\Sigma w$ s.t. $\sum w_i = 1, w^T\mu \geq r_p$ — quadratic program.
- **Production planning** (Bodin, Holst & Orlin 2012, MIT 15.053 case): shadow prices of machine hours drive capital investment.
- **Airline revenue management** (Belobaba 1987; Talluri & van Ryzin 2004): LP-based seat allocation.

### Deep Dive 2 — Network Flow Optimization
**網絡流優化**

#### Bilingual Concept Map

| English | 中英對照 | Definition | 物理意義 |
|---|---|---|---|
| Transportation problem | 運輸問題 | Min-cost shipment | 供需匹配 |
| Assignment problem | 分派問題 | Bipartite matching, optimal | 匈牙利算法 |
| Max-flow / min-cut | 最大流/最小割 | Ford-Fulkerson (1956) | 網絡瓶頸 |
| Shortest path | 最短路徑 | Dijkstra, Bellman-Ford, A* | 路徑規劃 |
| Min-cost flow | 最小成本流 | Min-cost circulation with supplies | 一般化運輸 |
| Minimum spanning tree | 最小生成樹 | Kruskal, Prim, reverse-delete | 網絡連接 |

#### Ford-Fulkerson Max-Flow / Min-Cut Theorem (Ford & Fulkerson 1956, *Canadian Journal of Mathematics*)

**Cut capacity**: For $(S, \bar{S})$ with $s \in S, t \in \bar{S}$:
$$c(S, \bar{S}) = \sum_{i \in S, j \in \bar{S}} c_{ij}.$$

**Theorem**: $\max |f| = \min_{S: s \in S} c(S, \bar{S})$ for all $s$-$t$ cuts.

**Algorithm (Edmonds-Karp = BFS augmenting path)**:
1. Find shortest $s$-$t$ path in residual graph by BFS.
2. Push $\Delta = \min_{(i,j) \in P} r_{ij}$ where $r_{ij}$ = residual capacity.
3. Update residual graph $r_{ij} \leftarrow r_{ij} - \Delta$, $r_{ji} \leftarrow r_{ji} + \Delta$.
4. Repeat until no augmenting path exists.

**Complexity**: $O(VE^2)$ (Edmonds-Karp; Karp 1972 *Complexity of Computer Computations*). With Dinic's blocking flow: $O(V^2\sqrt{E})$. Push-relabel (Goldberg & Tarjan 1988, *Journal of the ACM*): $O(V^2\sqrt{E})$; $O(VE\log(V^2/E))$ for unit capacities.

#### Transportation & Assignment Specializations

**Transportation** (Hitchcock 1941; Kantorovich 1942; Dantzig 1951): $\min \sum_{ij} c_{ij}x_{ij}$ s.t. $\sum_j x_{ij} = s_i$, $\sum_i x_{ij} = d_j$, $x_{ij} \geq 0$. Solvable by network simplex (Charnes & Cooper 1954) or successive shortest path.

**MODI method** (Reinfeld & Vogel 1958): $u_i, v_j$ row/column potentials, $u_i + v_j = c_{ij}$ on occupied cells. Reduced cost on empty cells: $\hat{c}_{ij} = c_{ij} - u_i - v_j \geq 0$ for optimality.

**Assignment problem** (Kuhn 1955, *Naval Research Logistics Quarterly*; Munkres 1957, *Journal of the SIAM*): bipartite graph with $n$ agents, $n$ tasks; $\min \sum c_{ij}x_{ij}$ s.t. $\sum_j x_{ij} = 1$, $\sum_i x_{ij} = 1$, $x \in \{0,1\}$. Hungarian algorithm in $O(n^3)$.

#### Engineering Applications

- **Water distribution**: minimum pumping cost, mass balance constraints, pressure limits.
- **Telecommunications**: maximum flow through fiber; min-cut = critical links.
- **Airline scheduling**: aircraft routing as min-cost flow in time-space network (each arc = flight leg, conservation at each aircraft).
- **Matching markets**: kidney exchange (Roth, Sönmez & Ünver 2004, *American Economic Review*).

### Deep Dive 3 — Integer Programming & Branch-and-Cut
**整數規劃與分支切割法**

#### Bilingual Concept Map

| English | 中英對照 | Definition | 物理意義 |
|---|---|---|---|
| Integer program | 整數規劃 | $x_j \in \mathbb{Z}$ for some $j$ | 離散決策 |
| Mixed-integer program (MIP) | 混合整數規劃 | Some variables integer, others real | 混合決策 |
| LP relaxation | LP鬆弛 | Drop integrality | 下界 / 上界 |
| Branch-and-bound | 分支定界 | Land-Doig 1960 | 系統枚舉 |
| Cutting plane | 切割平面 | Gomory 1958, lift-and-project | 收緊鬆弛 |
| Lagrangian relaxation | 拉格朗日鬆弛 | Dualize hard constraints | 下界 |
| Strong formulation | 強式定式 | Tight LP relaxation | 縮小差距 |

#### Branch-and-Bound (Land & Doig 1960; Dakin 1965)

**Problem**: $\max c^Tx$ s.t. $Ax \leq b$, $x \in \mathbb{Z}^n_+$.

**Algorithm**:
1. **Relax**: Solve LP → $z_{LP}, x_{LP}$. Bound: $z_{IP} \leq z_{LP}$.
2. **Bound**: Track incumbent $z_{best}$ from integer-feasible solutions.
3. **Branch**: If $x_j^{LP}$ fractional, split: $x_j \leq \lfloor x_j^{LP} \rfloor$ OR $x_j \geq \lceil x_j^{LP} \rceil$.
4. **Fathom**: prune subproblem if (a) LP infeasible, (b) $z_{LP} \leq z_{best}$, (c) integer solution (update $z_{best}$).

**Branching strategies**: most fractional variable, pseudo-cost branching, strong branching (Achterberg, Koch & Martin 2005).

#### Cutting Planes (Gomory 1958; Balas 1965)

**Gomory mixed-integer cut** (Gomory 1958, *Recent Advances in Mathematical Programming*, Ch. 14): from an LP tableau row $\bar{a}^Tx \leq \bar{b}$ with $\bar{b}$ fractional and integer components, generate
$$\sum_{j: \bar{a}_j > 0} \bar{a}_j x_j + \sum_{j: \bar{a}_j < 0} (\bar{b} - \bar{a}_j) x_j \leq \bar{b}$$
to cut off the fractional vertex without excluding integer points.

**Lift-and-project cuts** (Balas, Ceria & Cornuéjols 1993, *Mathematical Programming*); **knapsack covers** (Crowder, Johnson & Padberg 1983); **flow covers** (Gomory & Johnson 1972); **disjunctive cuts** (Balas 1979). Modern solvers (CPLEX, Gurobi) auto-generate dozens of cut types.

#### Lagrangian Relaxation (Held & Karp 1970, 1971)

For $\min c^Tx$ s.t. $Ax \leq b, x \in X$:
$$L(\lambda) = c^Tx + \lambda^T(Ax - b) \leq z_{IP}, \quad \forall \lambda \geq 0.$$
Subgradient optimization (Held, Wolfe & Crowder 1974, *Operations Research*): $\lambda_{k+1} = \lambda_k + \alpha_k (Ax_k - b)$, with $\alpha_k \to 0$ for convergence.

**Held-Karp bound** for TSP (1970, 1971): within 0.5–1% of optimal for $n = 1,000$ cities. Applegate, Bixby, Chvátal & Cook's Concorde (2006) routinely solves exact TSP up to 85,000 cities using LP relaxation + cutting planes + branch-and-bound.

#### Deep Test Question (numerical worked example)

Facility location (3 facilities, 4 customers): fixed costs $f_A = 200K, f_B = 180K, f_C = 150K$; demands $d_1 = 100, d_2 = 80, d_3 = 120, d_4 = 90$ units; shipping costs as in body.

(d) Solve both branches to integer optimal: open A and B (or A and C), ship optimally. Total ≈ \$1,800K + shipping ≈ \$1,540K.

### Deep Dive 4 — Dynamic Programming (Bellman 1957)
**動態規劃**

#### Bilingual Concept Map

| English | 中英對照 | Definition | 物理意義 |
|---|---|---|---|
| Bellman equation | 貝爾曼方程 | $V_k(i) = \min_u[C(i,u) + V_{k+1}(f(i,u))]$ | 遞推最優性 |
| State | 狀態 | $i$ = current info | 決策點狀態 |
| Action / decision | 動作 | $u$ = control | 選擇 |
| Stage | 階段 | $k$ = time/level | 問題分解單位 |
| Value function | 價值函數 | $V(i)$ = optimal cost from state $i$ | 最佳值 |
| Principle of optimality | 最優性原理 | Subsolution is optimal | 遞推基礎 |
| Curse of dimensionality | 維度詛咒 | Exponential state space | DP限制 |

#### Bellman's Principle of Optimality (Bellman 1957, *Dynamic Programming*)

> *"An optimal policy has the property that whatever the initial state and initial decision are, the remaining decisions must constitute an optimal policy with regard to the state resulting from the first decision."*

**Forward formulation**: $\min_u [C(i_0, u) + V(f(i_0, u))]$ with $V(i) = $ optimal future cost.

**Backward recursion**: $V_k(i) = \min_u [C_k(i,u) + V_{k+1}(f(i,u))]$ with $V_T(i) = $ boundary.

#### Worked Examples

**Shortest path** as DP: $V(i) = \min_{j \in N(i)}[c_{ij} + V(j)]$, $V(t) = 0$. Dijkstra's algorithm (1959) is forward computation with priority queue; A* (Hart, Nilsson & Raphael 1968) adds admissible heuristic $h(i)$: $V(i) = \min_j [c_{ij} + V(j)]$, priority by $f(i) = g(i) + h(i)$.

**Knapsack (0-1)** (Bellman 1957):
$$f(k, W) = \max[f(k-1, W),\; f(k-1, W-w_k) + v_k]$$
$f(0, W) = 0$, $f(k, 0) = 0$. Time $O(nW)$ — pseudopolynomial. Space reducible to $O(W)$ by rolling array (Kleinberg & Tardos 2006, Ch. 6).

**Inventory** $(s, S)$ policy (Scarf 1960, *Econometrica*; Clark & Scarf 1960): order up to $S$ when inventory < $s$. DP shows this is optimal for Markov demand. State = on-hand + on-order; cost = holding + backorder + setup.

**RCPSP** (resource-constrained project scheduling) — NP-hard in general (Blazewicz, Lenstra & Kan 1983); DP optimal for fixed resource capacity and bounded $n$.

#### Engineering Applications

- **Equipment replacement** (Wagner & Whitin 1958): state = equipment age; decision = keep or replace; cost = operating + replacement. Optimal threshold policy.
- **Inventory control**: $(s, S)$ is the de facto standard for stochastic demand.
- **NLP**: DP via state space, e.g., dynamic portfolio (Merton 1969, 1971).
- **RL**: Bellman equation is the foundation of value iteration, policy iteration, Q-learning (Sutton & Barto 2018).

### Deep Dive 5 — Nonlinear Programming and KKT
**非線性規劃與 KKT 條件**

#### Bilingual Concept Map

| English | 中英對照 | Definition | 物理意義 |
|---|---|---|---|
| KKT conditions | KKT條件 | Karush-Kuhn-Tucker (1939/1951) | 一階最優性 |
| Convex optimization | 凸優化 | $f$ convex, region convex | 全域最優保證 |
| Gradient descent | 梯度下降 | $x_{k+1} = x_k - \alpha_k \nabla f$ | 迭代下降 |
| Newton-Raphson | 牛頓法 | $x_{k+1} = x_k - H^{-1}\nabla f$ | 二階收斂 |
| Lagrange multiplier | 拉格朗日乘數 | $\mathcal{L} = f + \lambda^Tg$ | 約束邊際價值 |
| Lagrangian duality | 拉格朗日對偶 | $\max_{\lambda \geq 0}\min_x L(x,\lambda)$ | 下界 |
| Slaters condition | Slater條件 | Strictly feasible exists | 強對偶成立 |

#### KKT Conditions (Karush 1939; Kuhn & Tucker 1951)

**Problem**: $\min f(x)$ s.t. $g_i(x) \leq 0$, $h_j(x) = 0$.

**Lagrangian**: $\mathcal{L}(x, \lambda, \mu) = f(x) + \sum_i \lambda_i g_i(x) + \sum_j \mu_j h_j(x)$.

**Necessary conditions** (under constraint qualification, e.g., LICQ or MFCQ):
1. **Stationarity**: $\nabla f(x^*) + \sum_i \lambda_i \nabla g_i(x^*) + \sum_j \mu_j \nabla h_j(x^*) = 0$.
2. **Primal feasibility**: $g_i(x^*) \leq 0$, $h_j(x^*) = 0$.
3. **Dual feasibility**: $\lambda_i \geq 0$.
4. **Complementary slackness**: $\lambda_i g_i(x^*) = 0$.

**For convex problems** (Boyd & Vandenberghe 2004, Ch. 5): KKT sufficient.

#### Worked Example: Markowitz Portfolio as KKT

$\min w^T\Sigma w$ s.t. $\mathbf{1}^Tw = 1$, $\mu^Tw = r_p$.

Stationarity: $2\Sigma w - \lambda_1 \mathbf{1} - \lambda_2 \mu = 0$.

Solving: $w^* = \frac{1}{2}\Sigma^{-1}(\lambda_1 \mathbf{1} + \lambda_2 \mu)$.

Plug into constraints:
$$\lambda_1 (\mathbf{1}^T\Sigma^{-1}\mathbf{1}) + \lambda_2 (\mu^T\Sigma^{-1}\mathbf{1}) = 2,$$
$$\lambda_1 (\mathbf{1}^T\Sigma^{-1}\mu) + \lambda_2 (\mu^T\Sigma^{-1}\mu) = 2r_p.$$

This 2×2 linear system uniquely determines $\lambda_1, \lambda_2$. The dual value of $r_p$ traces out the **efficient frontier** as $r_p$ varies (Merton 1972).

#### Second-Order Conditions

For unconstrained critical point: $H(x^*) \succeq 0$ (PSD Hessian) is necessary for local min; $H \succ 0$ (PD) sufficient.

For constrained critical point: in the tangent space to active constraints, $y^T \nabla^2_{xx}\mathcal{L}(x^*) y > 0$ sufficient.

#### Algorithmic Methods

- **Gradient descent**: $O(1/k)$ for convex Lipschitz; $O((L/\mu)^k)$ for $\mu$-strongly convex.
- **Newton's method**: $O((\log\log 1/\epsilon))$ for self-concordant (Nesterov & Nemirovskii 1994).
- **SQP** (Han 1976; Powell 1978): iterate $x_{k+1} = x_k + d_k$ where $d_k$ solves quadratic subproblem.
- **Interior point** (Nesterov & Nemirovskii 1994): $O(n^{3.5}L)$ for convex programming.
- **ADMM** (Glowinski & Marroco 1975; Gabay & Mercier 1976; Boyd et al. 2011): decompose via augmented Lagrangian.

#### Deep Test Question
For $\min (x_1-2)^2 + (x_2-1)^2$ s.t. $g_1: x_1 + x_2 - 2 \leq 0$, $g_2: x_1 - x_2 \leq 0$.
(a) KKT conditions: $\nabla f = 2(x_1-2, x_2-1)$, $\nabla g_1 = (1,1)$, $\nabla g_2 = (1,-1)$. Stationarity: $2(x_1-2) + \lambda_1 + \lambda_2 = 0$, $2(x_2-1) + \lambda_1 - \lambda_2 = 0$.
(b) Case analysis: $g_1$ active ($\lambda_1 > 0$), $g_2$ inactive ($\lambda_2 = 0$). Then $x_1 + x_2 = 2$, $x_1 = x_2 = 1$. Check: $f^* = 1$, both constraints slack.
(c) Both active: $x_1 + x_2 = 2, x_1 = x_2$, giving $x_1 = x_2 = 1$ (same point). Both $\lambda_1, \lambda_2$ must be zero if constraints inactive at this point; verify via complementary slackness.

### Solution 5 — Strong Duality via Farkas' Lemma

**Q7.** **Farkas' Lemma** (Schrijver 1986, *Theory of Linear and Integer Programming*, Thm 2.1):
For $A \in \mathbb{R}^{m \times n}, b \in \mathbb{R}^m$, exactly one holds:
- (i) $\exists x \geq 0: Ax = b$,
- (ii) $\exists \lambda: A^T\lambda \leq 0, b^T\lambda > 0$.

**Proof of strong duality**:
Assume primal has optimal $x^*$ with $z^* = c^T x^*$. Let dual be feasible $\lambda$.

$c^T x^* = (c - A^T\lambda)^T x^* + (A^T\lambda)^T x^*$
$= (c - A^T\lambda)^T x^* + \lambda^T (Ax^*)$
$= (c - A^T\lambda)^T x^* + \lambda^T b$ (since $Ax^* = b$).

Since $c - A^T\lambda \geq 0$ (dual feasibility) and $x^* \geq 0$: $(c - A^T\lambda)^T x^* \geq 0$. Thus $c^T x^* \geq \lambda^T b$.

Therefore, $z^* \geq \sup_{\lambda \text{ feasible}} b^T \lambda = z_D$. By weak duality, $z^* \leq z_D$. Hence $z^* = z_D$.

**Existence of optimal $\lambda^*$**: From simplex optimal basis $B$, set $\lambda^* = c_B^T B^{-1}$. Then $A^T \lambda^* = c_B^T B^{-1} A$. For basic columns $A_j^T \lambda^* = c_B^T B^{-1} A_j = c_j$ (basis columns satisfy this); for non-basic, $\bar{c}_j = c_j - c_B^T B^{-1} A_j \geq 0$, so $A_j^T \lambda^* \leq c_j$. Hence $\lambda^*$ is dual-feasible. And $b^T \lambda^* = c_B^T B^{-1} b = z^*$.

**Required assumption**: primal feasibility + boundedness; equivalently, $P$ non-empty and $z$ bounded below.
